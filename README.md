# 📖 Overview

The Student Management System Frontend is built using React.js and provides an intuitive interface for managing student information.

Users can:

- View Students
- Add Students
- Edit Student Details
- Delete Students
- Search Students

The frontend communicates with the FastAPI backend through REST APIs.

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/PavanKumar9474/student-app.git
```

Go into Project

```bash
cd student-app
```

Install Dependencies

```bash
npm install
```

Run Project

```bash
npm run dev
```

---

# ⚙️ Configuration

Create a `.env` file.

```env
VITE_API_URL=http://127.0.0.1:8000
```
